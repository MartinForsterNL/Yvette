# TensorRT

Unpack TensorRT-8.6.1.6.Windows10.x86_64.cuda-12.0.zip here so you end up with:

```
TensorRT/
  TensorRT-8.6.1.6/
    lib/
    include/
    bin/
    python/
```

The install script finds TensorRT at TensorRT/TensorRT-8.6.1.6.

The actual TensorRT SDK files are NOT tracked by git (see .gitignore). You must
download TensorRT from NVIDIA yourself - it is proprietary and cannot be
redistributed.
