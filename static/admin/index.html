Voice cloning requirements

        
    
          
  • breeze — reference audio + exact transcript. Up to 60s (5–10s advised).
    • 
          
  • omnivoice — reference audio, auto-trimmed to 9s. Transcript optional.
    • 
          
  • lux — reference audio only (no transcript). ~5s used by default.
    • 
          
  • kokoro — no cloning (fixed preset voices).
    • 
        

        
Tip: clean speech, minimal background noise, no looping.
